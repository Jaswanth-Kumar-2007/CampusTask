# CampusTask 🎓

**CampusTask** is a simple and responsive to-do list application designed to help college students organize their assignments, study tasks, and personal activities in one place.

Built using HTML, CSS, and vanilla JavaScript with the assistance of Cursor AI, this project demonstrates how AI-powered development tools can help create a functional web application from scratch.

## ✨ Features

- **Add Tasks:** Create tasks with a title, category, and due date.
- **Task Categories:** Organize tasks into Assignments, Study, and Personal.
- **Mark as Completed:** Track your progress by completing tasks.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Filters:** View all, pending, or completed tasks.
- **Progress Tracking:** View total tasks and completed tasks.
- **Local Storage:** Keep your tasks saved in the browser, even after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile screens.
- **Input Validation:** Handle empty task titles and invalid input.

## 🛠️ Tech Stack

- **HTML5** — Application structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Task management and application functionality
- **LocalStorage API** — Persistent browser storage
- **Cursor AI** — AI-assisted development and debugging

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No backend, database, or additional dependencies are required.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/CampusTask.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CampusTask
   ```

3. Open `index.html` in your browser.

Alternatively, open the project folder in VS Code or Cursor and use the Live Server extension.

## 📁 Project Structure

```text
CampusTask/
```

- `index.html` — Defines the application structure.

## 💡 How It Works

1. Add a task by entering its title, category, and due date.
2. View your tasks in the dashboard.
3. Mark tasks as completed as you make progress.
4. Filter tasks to focus on pending or completed activities.
5. Refresh the page without losing saved tasks.

Tasks are stored in your browser using LocalStorage. Data is stored locally in the browser rather than in a remote database.
